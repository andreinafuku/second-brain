# Indice de Projetos

Mapa dos projetos ativos do vault. Esta nota serve como ponto de entrada para contexto, status, links e decisoes relevantes de cada iniciativa.

## Projetos ativos

- [[projeto-plataforma-oci-oke]]

## Estrutura sugerida para novos projetos

- Uma nota indice por projeto com objetivo, escopo, status, riscos e links principais.
- Wikilinks para pesquisas, referencias e termos do glossario usados nas decisoes.
- Se o projeto crescer, criar uma subpasta propria em `Projetos/`.

## Checklist para nova nota de projeto

- Objetivo e problema que o projeto resolve
- Escopo e fora de escopo
- Status atual
- Principais decisoes tecnicas
- Riscos e dependencias
- Links para pesquisas e referencias relacionadas
