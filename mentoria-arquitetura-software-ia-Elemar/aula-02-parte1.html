Tese central

Arquitetura de software é complexa

Mais de uma solução viável. A melhor só aparece com contexto + teste.

Arquitetura tratada como problema complexo
Erro comum

“Vamos fazer assim porque a Netflix faz.”

Problema parecido ≠ contexto igual

  • Escala diferente
  • Orçamento diferente
  • Restrições diferentes
  • Serviços e operação diferentes
Na aula: copiar referências sem contexto é uma justificativa fraca

Papel da IA

IA não substitui o arquiteto. IA acelera experimentação.

IA faz bem

  • Gerar variações
  • Criar protótipos
  • Apoiar documentação
  • Acelerar iteração

Humano continua essencial

  • Contexto
  • Julgamento
  • Validação
  • Decisão final
IA acelera o processo; não elimina validação humana
Ganho real

O ganho não é fazer tela mais rápido

O ganho é validar hipótese mais rápido.
