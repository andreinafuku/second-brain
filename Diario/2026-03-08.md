## Pergunta registrada

No fluxo de caixa, ao chamar o endpoint `/api/tesouraria/visoes-fluxos-caixa/${visaoId}/dados`, a API retorna todos os dados referentes as dimensoes de uma unica vez, o que prejudica a performance ao carregar o grid.

A ideia seria a API aceitar query params, como `dimLin1`, `dimLin2` e assim por diante, de acordo com o fluxo definido pelo usuario. Exemplo: `dimLin1=conta-financeira-001`.

No front-end, isso poderia ser disparado a partir do clique no `ExpandButtonRenderer.vue`, populando as celulas sob demanda. O comportamento esperado seria:

- carga inicial com os dados consolidados da primeira dimensao visivel
- clique nos botoes de expansao disparando novos parametros para a API
- preenchimento incremental do grid conforme a navegacao do usuario

Pergunta: isso e viavel? Como implementar essa abordagem no front-end e no backend?
